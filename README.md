# Spicy Store – Modern E-Commerce Frontend
**Browse products. Add to cart. Checkout. All in the browser. Lightning fast.**

🔗 [Live Demo](https://shafikulnayem10.github.io/Spicy_Store/)

---

## The Problem
E-commerce sites are slow. Cart management is clunky. Users refresh the page and lose their cart. You need a fast, responsive shopping experience that works offline and doesn't lose data.

## The Solution
Spicy Store delivers:
- **Fast product browsing** — Instant search across entire catalog  
- **Smooth cart** — Add/remove items, see total update instantly  
- **Dynamic pages** — Click a product, see full details  
- **Seamless routing** — Navigate without page reloads  
- **Data persists** — Cart survives browser closes via localStorage  
- **Works on mobile** — Fully responsive, tested on all devices  

---

## What I Built
✅ **React component architecture** — Reusable, scalable, maintainable  
✅ **Client-side routing** — React Router for multi-page experience  
✅ **Cart state management** — Real-time updates with useState hooks  
✅ **localStorage persistence** — Cart data survives page refreshes  
✅ **Dynamic product pages** — Route params for individual product details  
✅ **Real-time search** — Instant filtering across products  
✅ **Responsive UI** — Tailwind + DaisyUI, optimized for all screens

## How to Run
```bash
git clone <repo>
cd spicy-store
npm install
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173)
